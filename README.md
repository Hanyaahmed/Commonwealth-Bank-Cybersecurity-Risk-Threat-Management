# Commonwealth Bank Cybersecurity Risk and Threat Management
## Objective

This project simulates the role of a Cybersecurity Generalist within Commonwealth Bank’s Cybersecurity team, focusing on fraud detection, incident response, security awareness, and penetration testing. Through real-world tasks, the experience emphasized proactive threat identification, response coordination, and security education in a financial services environment.

The goal was to strengthen practical cybersecurity and analytical skills by applying industry-standard tools, frameworks, and communication methods to real-world business challenges.

## Skills Learned

- Fraud Detection & Data Analysis using historical customer data.

- Incident Response Management including identification, containment, and recovery.

- Security Awareness Development and communication of best practices.

- Penetration Testing for web application vulnerability assessment.

- Dashboard Creation with Splunk for threat visualization and analysis.

- Report Writing & Stakeholder Communication under simulated enterprise conditions.

## Tools Used

- Splunk – for log analysis and dashboard creation.

- Excel / Google Sheets – for data inspection and visualization.

- Commonwealth Bank Forage Platform – for simulation tasks and scenario-based learning.

- Cybersecurity Frameworks: NIST, ISO 27001, and ACSC Essential Eight principles.

# Steps
## Task 1: Data Analysis — Fraud Detection

`Objective: Build a data visualization dashboard to identify suspicious activity in historical customer datasets.`

`Process:`

- Imported and cleaned datasets using spreadsheet tools.

- Used Splunk-style visualization logic to uncover transaction anomalies.

- Interpreted results to distinguish legitimate customer activity from fraud indicators.

  `Outcome: Demonstrated the ability to translate raw financial data into actionable fraud insights.`
